### Först lite basics för att förstå uppbyggnaden


- Möjligheten att skapa olika element med hjälp av taggar
- Taggarna talar om vad som kommer ske, *innanför* taggen
- En starttagg talar om vart taggen startar
- En sluttagg talar om vart taggen slutar


---
# *starttagg:* < tagg >  
# *sluttagg:* < / tagg >
---

### Strukturtaggar

< html > : Elementet som knyter ihop hela hemsidan. Detta är din **start**.

< head > : Innehåller metadata, dvs. data om datan.

< body > : Här förekommer allt synligt på själva webbsidan. Rubriker, text, bilder länkar etc.
